# QA Manual Testing Portfolio

Proyecto realizado durante el curso de **QA Manual en Coderhouse**.

## Descripción

Este repositorio reúne las actividades desarrolladas durante el proyecto final del curso, aplicando técnicas de aseguramiento de la calidad (QA) sobre aplicaciones web y APIs.

Las tareas realizadas incluyen:

- Diseño de casos de prueba.
- Ejecución de pruebas funcionales.
- Reporte de bugs.
- Elaboración de informes de resultados.
- Pruebas de APIs con Postman.
- Análisis de rendimiento con Lighthouse.
- Pruebas de carga utilizando k6.

## Herramientas utilizadas
