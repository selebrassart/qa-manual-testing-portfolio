# QA Manual Testing Portfolio

Proyecto realizado durante el curso de **QA Manual en Coderhouse**, aplicando técnicas de aseguramiento de calidad sobre aplicaciones web reales y una API pública.

## Resumen de resultados

- **10 casos de prueba** diseñados y ejecutados (positivos y negativos) sobre el formulario de registro y login de Guru99 - Mercury Tours, detectando defectos críticos de validación de campos.
- **3 reportes de bugs** documentados con pasos de reproducción, resultado esperado vs. obtenido, criticidad y entorno.
- **10 casos de prueba de API** sobre [PokeAPI](https://pokeapi.co/) con Postman (5 exitosos, 5 negativos: métodos no permitidos, endpoints inválidos, recursos inexistentes).
- **Análisis de performance y carga** sobre un sitio de e-commerce con Lighthouse (desktop/mobile) y k6 (50 usuarios concurrentes), identificando tiempos de respuesta de hasta 18 segundos bajo carga.

## Descripción

Este repositorio reúne las actividades desarrolladas durante el proyecto final del curso, aplicando técnicas de QA sobre tres casos de uso distintos:

1. **Testing funcional manual** — formulario de registro/login (Guru99 - Mercury Tours).
2. **Testing de API** — endpoints de PokeAPI.
3. **Testing de performance y carga** — sitio de e-commerce.
